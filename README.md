## 💻 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone git@github.com:SimpleSoftwareLTDA/treinamento-descomplica-dev-na-gringa.git
   cd treinamento-descomplica-dev-na-gringa
   ```

2. Instale as dependências com o Bun:
   ```bash
   bun install
   ```

3. Compile o CSS e o JS:
   ```bash
   bun run build
   ```

4. Inicie o servidor local:
   ```bash
   bun run start
   ```
